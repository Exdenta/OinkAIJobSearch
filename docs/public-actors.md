# Public Actor directory

Checked on 4 October 2026: **76 public Nomad Agent Actors and 17 public Job Atlas copies**. Every endpoint below has its own Actor ID, input schema, pricing and build history. Choose the exact Actor for your data; similarly named copies are separate endpoints.

These descriptions explain what each product returns. Public availability and listing metadata were checked with read-only Apify API calls; no Actors were run during this check. A listing or build does not prove complete source coverage, a successful search, enabled optional processing or delivery to your application.

Read the current **Input**, **Output** and **Pricing** tabs before use. Select `latest`, keep API tokens in the environment, start with a small result and cost limit, and record the immutable build returned by each run. Filters and repeat suppression can produce fewer results or an empty dataset. Where available, inspect `RUN-SUMMARY` separately from data rows.

Simple job Actors return source facts; normalized job Actors use the nested `nomad-agent-job-v1` format. AI job search and fit scoring have their own contracts. Optional AI enrichment or translation must be selected according to the exact Actor input. Menu Actors with customer-supplied keys and managed menu Actors are distinct products; do not apply job inputs to them.
